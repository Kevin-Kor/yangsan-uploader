1. 수집하는 정보

이 도구는 채널 소유자가 Google 로그인으로 직접 승인한 경우에만 아래 정보에 접근합니다.

  • YouTube 업로드 권한(youtube.upload): 운영자가 제작한 영상을 해당 채널에 업로드하고 공개 예약을 설정하는 데만 사용합니다.
  • YouTube 읽기 권한(youtube.readonly): 업로드 대상 채널이 맞는지 확인하기 위해 채널 이름과 ID를 읽는 데만 사용합니다.

시청자 정보, 댓글, 구독자 목록, 이메일 등 그 밖의 개인정보는 수집하지 않습니다.

2. 저장과 보관

Google이 발급한 인증 토큰은 운영자 컴퓨터에만 저장되며(접근 권한이 제한된 로컬 파일), 외부 서버로 전송하거나 데이터베이스에 보관하지 않습니다. 토큰은 승인이 철회되거나 운영자가 삭제하면 더 이상 사용되지 않습니다.

3. 제3자 제공

Google 사용자 데이터를 판매하거나 제3자와 공유·이전하지 않으며, 광고 목적으로 사용하지 않습니다. 이 도구의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

5. 접근 권한 철회

언제든지 Google 계정 권한 설정에서 이 앱의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 즉시 무효가 됩니다. 운영자에게 요청하면 로컬에 저장된 토큰 파일도 삭제합니다.

What we access. Only after a channel owner signs in with Google and grants access: the youtube.upload scope, used solely to upload the operator's videos to that channel and set their publish schedule; and the youtube.readonly scope, used solely to read the channel name and ID to confirm the upload destination. YouTube API Services. This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access. You can revoke access at any time at Google Account permissions. On request, the operator also deletes the locally stored token files.
